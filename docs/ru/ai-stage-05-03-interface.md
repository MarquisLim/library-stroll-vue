# Интерфейс AI-ассистента Library Stroll

## 5.3-1 — Базовый интерфейс AI-ассистента

`GET /assistant` (`assistant.index`) открывает рабочее пространство внутри общего `AppLayout`. Маршрут использует защищённую веб-группу, проверку веб-сессии, подтверждённого email и `AI_ASSISTANT_ENABLED`. При выключенном флаге допущенный пользователь получает 404. В общих свойствах Inertia передаётся один признак `canUseAssistant`, который управляет ссылкой в верхней навигации и мобильном меню. Открытие страницы не вызывает AI-сервисы и не расходует поисковую квоту. [Маршрут](../../routes/web.php) · [Защита](../../app/Http/Middleware/AuthorizeAssistantSearch.php).

### Поиск и состояния

Страница отправляет `POST /assistant/search` с полями `query` и `limit: 10`. Действующая квота Laravel — 10 запросов в минуту на пользователя. `ok` показывает карточки в порядке API, `no_results` предлагает изменить фразу, `clarification_required` показывает фиксированную подсказку по коду, включая общий вариант для неизвестного кода. Ссылка принимается только в форме `/artworks/{artwork_id}` с соответствующим числовым ID. Каноническая страница публикации применяет свою проверку прав при переходе.

Ожидание сопровождается индикатором и текстом «Ищем подходящие работы…». Повторная отправка во время запроса блокируется. Прежние сообщения остаются видны при сбое, а повтор выполняется по кнопке. HTTP 401, 403, 404, 413, 419, 422, 429, 503 и сетевые ошибки показываются понятным текстом. `AbortController` отменяет ожидание в браузере, а идентификатор запроса защищает от запоздалых ответов после очистки или ухода со страницы. Серверная обработка уже отправленного запроса может продолжаться.

Каждая фраза обрабатывается отдельно. Разговор хранится только в состоянии текущей страницы и очищается при её обновлении либо кнопкой «Новый диалог». RAG и API истории в этом интерфейсе ещё не используются. Карточки показывают название и ссылку. Контракт поиска не выдаёт превью, а защищённый путь для превью с нужными ограничениями предстоит проверить в 5.3-2.

### Запуск и проверки

В локальном исследовательском окружении установите `AI_ASSISTANT_ENABLED=true`. Для Hybrid Search должен быть настроен действующий AI-сервис с `AI_SERVICE_ENABLED=true`; доступный лексический поиск может работать самостоятельно. Соберите ресурсы через `npm run build` либо запустите `npm run dev`, войдите подтверждённым пользователем и откройте `/assistant` через навигацию. Скопируйте один из предложенных запросов в поле кнопкой примера, отправьте его и откройте найденную работу.

## 5.3-2 — Диалоги, история, RAG и источники

Страница `/assistant` использует прежний `AppLayout` и компоненты чата. Слева появилась сворачиваемая панель истории шириной 272 px. На узких экранах она открывается как модальный drawer, удерживает фокус и закрывается по Escape, нажатию вне панели или выбору диалога. Названия в списке используют дату создания. Это позволяет вывести список без чтения чужого содержимого, дополнительных запросов к каждому диалогу или вызовов модели. [Страница](../../resources/js/Pages/Assistant/Index.vue) · [Панель истории](../../resources/js/Components/Assistant/AssistantSidebar.vue).

### Режимы запуска

В изолированном окружении включите нужные возможности на стороне Laravel и FastAPI, соберите ресурсы `npm run build` и войдите подтверждённым аккаунтом.

```dotenv
AI_ASSISTANT_ENABLED=true
AI_ASSISTANT_RAG_ENABLED=true
AI_ASSISTANT_HISTORY_ENABLED=true
AI_ASSISTANT_CONTEXT_ENABLED=true
```

Три свойства страницы сообщают браузеру доступность истории, совместную доступность истории и RAG и возможность контекстного уточнения. При отключении истории или RAG поле ввода использует независимый `POST /assistant/search`. Если история доступна отдельно, её можно читать и удалять. Чтение и удаление выполняет Laravel без вызова модели. Отключённый контекст обозначен под полем ввода. [Маршруты](../../routes/web.php).

### История и источники

- Список загружается с `GET /assistant/conversations` постранично. «Новый диалог» очищает рабочую область. `POST /assistant/conversations` создаёт запись при первой отправке.
- `POST /assistant/conversations/{uuid}/turns` получает только `query` и `limit`. Следующее сообщение использует тот же UUID. Выбор контекста остаётся на сервере.
- При открытии явно выполняется `GET /assistant/conversations/{uuid}`. Ходы сортируются по `sequence`, страницы объединяются по UUID, прокрутка сохраняет позицию при загрузке ранних сообщений. Удаление требует подтверждения и использует `DELETE /assistant/conversations/{uuid}`.
- Ссылки `[1]`, `[2]` сопоставляются с допустимыми `source_ref` того же хода. Название `null` отображается как «Без названия». Фрагменты отображаются как текст. При `partial` и `unavailable` видны только актуальные сведения из свежего ответа сервера. Карточки `search_fallback` доступны в текущем ответе, но архитектура хранения не восстанавливает их при чтении истории.
- Запросы, ответы и источники остаются в памяти страницы. Локальное и сессионное хранилища браузера для них не используются. [Состояние диалога](../../resources/js/composables/useAssistantConversation.js) · [Обработка цитат](../../resources/js/composables/assistantReplies.js).

### Миниатюры

`GET /assistant/artworks/{artwork}/preview` требует веб-сессию, подтверждённый email и включённый ассистент. Контроллер заново проверяет публикацию, публичность, блокировки, разрешение AI-индексации, наличие оригинального изображения и `ArtworkPolicy::view`. Для взрослых работ миниатюра закрыта. Ответ содержит только уже существующую конверсию `thumb` в WebP, PNG или JPEG размером до 2 МиБ и выставляет `private, no-store` и `nosniff`. При восстановлении карточки меняется технический параметр URL, чтобы повторно пройти серверную проверку даже в той же вкладке с уже декодированным изображением. При отсутствии безопасного файла карточка сохраняет название и каноническую ссылку. Чтение не запускает обработку медиа и не расходует квоту ассистента. [Контроллер](../../app/Http/Controllers/AssistantArtworkPreviewController.php) · [Проверки](../../tests/Feature/AssistantArtworkPreviewTest.php).

### Конфликты и ошибки

Смена диалога и очистка отменяют ожидание, а проверка операции и UUID защищает от поздних ответов. HTTP 409 обновляет историю или список, сообщает о возможном конфликте, лимите или изменении источников. При отмене и неопределённом результате сохранение могло состояться. Интерфейс предлагает обновить историю или список, затем при необходимости позволяет вернуть исходную фразу в поле. Повторный POST остаётся явным действием пользователя. Сервер может завершить прерванную операцию уже после проверки истории.

### Проверки

- Сборка `npm run build` прошла с предупреждением Vite о крупном чанке приложения.
- PHP — 159 тестов и 1192 утверждения на SQLite в памяти. Покрыты API этапов 5.0 и 5.1, доступ к странице, режимы и выдача миниатюр. Проверены отзыв доступа, заблокированные и взрослые работы, отсутствующая и недопустимая миниатюра, сохранение поисковой квоты.
- JavaScript — 20 тестов. Проверены первый ход, контекстный UUID, пагинация, отмена, конфликты, запоздалые ответы, восстановление и удаление, безопасные ссылки, название `null` и повторная проверка миниатюры. [Тесты диалога](../../tests/js/assistant-conversation.test.mjs).

В Edge проверены 1920 × 1080, 1440 × 900, 768 × 1024 и 390 × 844 в светлой и тёмной темах. Проверены сворачивание панели, фокус после Escape, закрытие по нажатию вне панели и после выбора диалога. При имитации мобильной клавиатуры область 390 × 500 сохраняет доступ к полю ввода над нижней навигацией.

Через Nginx на loopback в изолированном `library-stroll-51-dialogue` проверены настоящие Laravel, MySQL, FastAPI, Ollama `qwen3:8b` и Qdrant. Первый запрос о птицах у воды получил 201 с пятью подтверждёнными фрагментами и тремя карточками. WebP-миниатюры отрисовались через защищённый маршрут. Вопрос о XIX веке ушёл в тот же диалог. Снимки исследовательских данных совпали, тома сохранены, контейнеры остановлены.
