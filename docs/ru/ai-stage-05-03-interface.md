# Интерфейс AI-ассистента Library Stroll

## 5.3-1 — Базовый интерфейс AI-ассистента

`GET /assistant` (`assistant.index`) открывает рабочее пространство внутри общего `AppLayout`. Маршрут использует защищённую веб-группу, проверку веб-сессии, подтверждённого email и `AI_ASSISTANT_ENABLED`. При выключенном флаге допущенный пользователь получает 404. В общих свойствах Inertia передаётся один признак `canUseAssistant`, который управляет ссылкой в верхней навигации и мобильном меню. Открытие страницы не вызывает AI-сервисы и не расходует поисковую квоту. [Маршрут](../../routes/web.php) · [Защита](../../app/Http/Middleware/AuthorizeAssistantSearch.php).

### Поиск и состояния

Страница отправляет `POST /assistant/search` с полями `query` и `limit: 10`. Действующая квота Laravel — 10 запросов в минуту на пользователя. `ok` показывает карточки в порядке API, `no_results` предлагает изменить фразу, `clarification_required` показывает фиксированную подсказку по коду, включая общий вариант для неизвестного кода. Ссылка принимается только в форме `/artworks/{artwork_id}` с соответствующим числовым ID. Каноническая страница публикации применяет свою проверку прав при переходе.

Ожидание сопровождается индикатором и текстом «Ищем подходящие работы…». Повторная отправка во время запроса блокируется. Прежние сообщения остаются видны при сбое, а повтор выполняется по кнопке. HTTP 401, 403, 404, 413, 419, 422, 429, 503 и сетевые ошибки показываются понятным текстом. `AbortController` отменяет ожидание в браузере, а идентификатор запроса защищает от запоздалых ответов после очистки или ухода со страницы. Серверная обработка уже отправленного запроса может продолжаться.

Каждая фраза обрабатывается отдельно. Разговор хранится только в состоянии текущей страницы и очищается при её обновлении либо кнопкой «Новый диалог». RAG и API истории в этом интерфейсе ещё не используются. Карточки показывают название и ссылку. Контракт поиска не выдаёт превью, а защищённый путь для превью с нужными ограничениями предстоит проверить в 5.3-2.

### Запуск и проверки

В локальном исследовательском окружении установите `AI_ASSISTANT_ENABLED=true`. Для Hybrid Search должен быть настроен действующий AI-сервис с `AI_SERVICE_ENABLED=true`; доступный лексический поиск может работать самостоятельно. Соберите ресурсы через `npm run build` либо запустите `npm run dev`, войдите подтверждённым пользователем и откройте `/assistant` через навигацию. Скопируйте один из предложенных запросов в поле кнопкой примера, отправьте его и откройте найденную работу.

- Сборка `npm run build` прошла. Vite предупредил о крупном чанке приложения.
- PHPUnit на SQLite в памяти с HTTP-моками — **149 тестов, 1052 утверждения**. Проверены новая страница, запреты доступа, флаг, отсутствие вызовов AI и расхода квоты при открытии, регрессии поиска, RAG и истории. [Тест страницы](../../tests/Feature/AssistantPageTest.php).
- `node --test` по `tests/js` — **10 тестов**, включая шесть тестов ассистента. Проверены порядок, канонические ссылки, состояния, явный повтор, лимит, отмена и игнорирование запоздалого ответа. [Тесты поиска](../../tests/js/assistant-search.test.mjs).

В локальном Edge проверены 1920 × 1080, 1440 × 900, 768 × 1024 и 390 × 844 в обеих темах. Горизонтальной прокрутки нет, включая случай с запросом в 500 символов и длинным названием без пробелов. Лента прокручивается отдельно, поле ввода остаётся над нижней навигацией. Проверены порядок Tab и видимый фокус. Экранная клавиатура проверена по уменьшенной высоте viewport 390 × 500 с полем в фокусе. Физическое мобильное устройство в прогоне не использовалось.

Браузер вошёл в Laravel тестовым подтверждённым аккаунтом и отправил запрос с настоящей веб-сессией и CSRF. Лексический поиск вернул восемь записей из отдельной SQLite. Каноническая ссылка открыла публикацию, поисковая фраза без совпадений дала пустую выдачу. HTTP 503, уточнение и задержку для проверки отмены воспроизвели перехватом запросов в браузере. FastAPI, Ollama, Qdrant и исследовательский корпус в этом браузерном прогоне не использовались. [Результаты браузерного прогона](../../storage/app/ai-stage-05-03/5.3-1/browser-results.json).
