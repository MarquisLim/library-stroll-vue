# Каталог документации проекта

Дата обзора: 24 октября 2026 года. Каталог фиксирует 89 исходных Markdown-файлов (557157 байт) до добавления отчёта в `docs/ru`.

Основной результат аудита: [Ollama, векторы и семантический поиск](ollama-semantic-search-audit.md).

## Как читать материалы

`docs/ai` и `ai-service/README.md` описывают текущий AI-контур. `docs/assignment-1`–`docs/assignment-5` содержат учебные модели, проектные варианты, примеры и оценки; наличие компонента на диаграмме не доказывает его внедрение. `case-tool` и генератор DFD → UML — вспомогательные инструменты моделирования. Метаданные DSM в задании 4 описывают формы и таблицы, а AI-метаданные — содержание изображения; это разные механизмы.

## Основные расхождения с работающим приложением

- Корневой README — шаблон Laravel: он не объясняет запуск LibraryStroll и AI.
- В assignment-2 и assignment-5 показаны кластеры, Redis, Elasticsearch, Vue Router и другие проектные варианты. В текущем поисковом коде работают SQL `LIKE`, HTTP-клиент Python и RRF; Elasticsearch и отдельный Vue Router по зависимостям и маршрутам не подключены.
- `docs/assignment-4/prototype/README.md` описывает `/api/meta/*`, `DynamicForm` и `DynamicTable`; соответствующих действующих маршрутов и Vue-компонентов в основном приложении не обнаружено. Прототип не следует разворачивать поверх рабочей базы по его примеру `.env`.
- В assignment-5 есть Python-примеры сервисов и упоминание React Native. В основном приложении используются Laravel/PHP, Vue/Inertia и Capacitor; примеры из задания не являются действующим AI-сервисом.
- Команда `ai:evaluate` из `docs/ai/evaluation-plan.md` отсутствует в Artisan. Это план оценки качества, а не готовый измерительный инструмент.
- В Windows-инструкции `queue:work --queue=ai --timeout=300` не согласован с `retry_after=240`. Нужен больший интервал повторной выдачи задания.
- В API rerank есть только возврат исходного порядка; включение PHP-флага не добавляет модель переранжирования.
- `resources/markdown/policy.md` и `terms.md` — короткие шаблоны. Отдельные публичные юридические Vue-страницы следует рассматривать независимо.
- В старых инструкциях встречаются пути `C:\OSPanel\domains\...` и ссылки на перенесённые или отсутствующие файлы (`docs/metamodeling-plan.md`, `docs/report-example.md`, `experiment/demo.md`). Актуальный проверенный корень — `B:\projects\library-stroll-vue`.

После аудита добавлена [практическая инструкция импорта артов](data-import.md), а в корневом README появились команды подготовки базы и музейного импорта. Список выше остаётся снимком исходных 89 документов на момент аудита.
