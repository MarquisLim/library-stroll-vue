### 4.1.2B-1. Автоматическая переиндексация

`ai:reconcile` больше не выбирает `indexed` по возрасту `indexed_at`. Сохранены правила для `stale`, зависшего `processing`, `failed` с доступными попытками, старого `pending` и опубликованных работ без AI-метаданных. Изменения названия, описания или тегов по-прежнему запускают индексацию через существующий путь обновления. Устаревший `--stale-hours` принимается для совместимости и игнорируется. Сверка точек отнесена к 4.1.2B-2. Восстановление 21 записи не выполнялось.

Два последовательных такта расписания проверены на SQLite в памяти с `Queue::fake()`. Рабочий Scheduler в рамках проверки не обновлялся.
