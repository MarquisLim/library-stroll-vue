# 4.8A-1 — Независимый набор поисковых запросов

Для оценки семантического поиска подготовлены 40 новых запросов к тем же 100 изображениям 4.4C (`441001–441100`). Тексты, оценки и список спорных пар зафиксированы до получения выдачи. Независимость относится к поисковому ранжированию. Это первоначальная визуальная разметка, выполненная AI-ассистентом. Человеческой экспертной проверки пока не было.

## Как подготовлен набор

1. Проверен SHA-256 манифеста 4.4C и всех 100 исходных файлов. Полный набор просмотрен на контактных листах, 24 работы дополнительно просмотрены в увеличенном масштабе для проверки деталей и близких случаев.
2. Формулировки составлены по видимым признакам. Запросы охватывают отдельные объекты, цвет, фактуру, освещение, расположение предметов и сочетания признаков. Есть 5 коротких формулировок по 4 слова и 9 запросов из 10 и более слов. Диапазон от 4 до 17 слов.
3. После составления выполнено сравнение с прежними планами 4.4C–4.6A и сохранённым поисковым текстом 100 работ. Совпадений полных нормализованных запросов и дословных фрагментов из пяти последовательных слов не найдено. Поисковые тексты использованы только для проверки совпадений формулировок.
4. Для запроса размечены несколько подходящих работ, а также визуально близкие или тематические примеры, которым недостаёт нужных признаков. Для каждой пары указано, что именно видно на изображении и чего не хватает. Dense, ColBERT и гибридный поиск для новых запросов не выполнялись.

Идентификаторы запросов `1–20` относятся к русскому набору, `21–40` к английскому. Категория описывает намерение запроса. Одна работа может подходить к запросам разных категорий. Например, изображение рельефа с птицами подходит по способу изображения птиц и по форме музейного предмета.

## Разметка релевантности

| Оценка | Правило | Пар |
| ---: | --- | ---: |
| 2 | Видны основные признаки запроса и их сочетание | 73 |
| 1 | Видна существенная часть признаков, одного или нескольких ключевых не хватает | 60 |
| 0 | Явно отсутствуют признаки, определяющие запрос | 40 |

Всего в `qrels.json` 173 пары по 89 изображениям. У всех 40 запросов есть хотя бы две оценки выше нуля, у 23 запросов есть хотя бы две оценки 2. Например, для № 8 оба эскиза `441014` и `441087` хорошо подходят к описанию стены со скульптурным декором, а `441061` получает 1 за похожий декор в пейзажной композиции. Для № 34 хорошо подходят пять натюрмортов с посудой на тёмном фоне.

Отдельно сохранены 16 спорных пар. Для каждой записаны видимый признак, возможные значения и вопрос для проверки. Например, у `441076` в № 22 видны деревья и полоса воды, но фактуру воды трудно отличить от берега. Такие пары не входят в qrels.

Разметка выборочная. Отсутствие пары означает «не оценено». Оценку 0 имеют только явно проверенные неподходящие примеры. Корпус остаётся тем же, что использовался раньше. Новый набор даёт другие поисковые формулировки, но не проверяет переносимость на новый корпус. Баланс языков задан при составлении, а распределение по категориям отражает состав доступных изображений.

## Зафиксированные файлы

Файлы сохранены локально в `storage/app/ai-stage-04-08`.

| Файл | Содержимое |
| --- | --- |
| `query-plan.json` | ID, язык, текст и категория каждого запроса |
| `qrels.json` | ID запроса и работы, оценка 0–2 и обоснование для каждой пары |
| `review-needed.json` | Спорные пары, возможные оценки и вопросы для визуальной проверки |
| `dataset-images.json` | ID, путь от каталога 4.4C, SHA-256 и размеры каждого оригинала |
| `checksums.json` | SHA-256 четырёх файлов, манифеста, набора изображений и прежних планов |

Хеш набора изображений рассчитан по строкам `artwork_id SHA-256` в порядке возрастания ID, UTF-8 без BOM, с LF после каждой строки. Проверены баланс языков, ссылки на работы и запросы, уникальность пар и отсутствие пересечения между qrels и списком спорных случаев. Все 100 хешей повторно сверены с манифестом после разметки.
