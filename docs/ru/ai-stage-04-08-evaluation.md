# 4.8A-1 — Независимый набор поисковых запросов

Для оценки семантического поиска подготовлены 40 новых запросов к тем же 100 изображениям 4.4C (`441001–441100`). Тексты, оценки и список спорных пар зафиксированы до получения выдачи. Независимость относится к поисковому ранжированию. Это первоначальная визуальная разметка, выполненная AI-ассистентом. Человеческой экспертной проверки пока не было.

## Как подготовлен набор

1. Проверен SHA-256 манифеста 4.4C и всех 100 исходных файлов. Полный набор просмотрен на контактных листах, 24 работы дополнительно просмотрены в увеличенном масштабе для проверки деталей и близких случаев.
2. Формулировки составлены по видимым признакам. Запросы охватывают отдельные объекты, цвет, фактуру, освещение, расположение предметов и сочетания признаков. Есть 5 коротких формулировок по 4 слова и 9 запросов из 10 и более слов. Диапазон от 4 до 17 слов.
3. После составления выполнено сравнение с прежними планами 4.4C–4.6A и сохранённым поисковым текстом 100 работ. Совпадений полных нормализованных запросов и дословных фрагментов из пяти последовательных слов не найдено. Поисковые тексты использованы только для проверки совпадений формулировок.
4. Для запроса размечены несколько подходящих работ, а также визуально близкие или тематические примеры, которым недостаёт нужных признаков. Для каждой пары указано, что именно видно на изображении и чего не хватает. Dense, ColBERT и гибридный поиск для новых запросов не выполнялись.

## 4.8A-2 — Сравнение поисковых методов

Эксперимент использует зафиксированные 40 запросов, 173 оценки и 16 спорных пар из 4.8A-1. До запуска сверены SHA-256 входных файлов, манифеста, всех 100 оригиналов, текстов документов 4.5A и файлов ColBERT. Состав исходного индекса проверен по контрольным суммам 4.4C.

| Метод | Выполнение |
| --- | --- |
| A | Dense через FastAPI, `qwen3-embedding:0.6b` и Qdrant |
| B | Тот же Dense и ColBERT для первых 30 кандидатов с сохранением порядка позиций 31–50 |
| C | Текущий Laravel Hybrid Search с LIKE и RRF, флаг ColBERT выключен |
| D | Текущий Laravel Hybrid Search с LIKE, RRF и включённым ColBERT |

Для всех режимов выбран тестовый автор, включена штатная проверка публичности. Лимиты равны 50 для Dense, 50 для LIKE и 30 для ColBERT, `rrf_k=60`. Гибридный запрос получает до 100 работ. Полные списки сохраняются со score и порядком. Для каждого режима Dense выполнен реальным запросом, его порядок и оценки сверены между A–D. Вход RRF наблюдался через измерительный скрипт, который вызывает штатный `ReciprocalRankFusion`.

После старта выполнен прогрев двумя запросами 4.5A в каждом режиме. В измерении порядок четырёх режимов циклически менялся по номеру запроса. Измерено серверное время от вызова клиента или Hybrid Search до возврата результата в Laravel. Времена холодного запуска, подготовки документов и прогрева учтены отдельно.

### Правила подсчёта

nDCG использует градации 0, 1 и 2, прирост `2^grade − 1` и дисконт `log₂(позиция + 1)`. Идеальный порядок строится из всех известных оценок запроса, включая работы за пределами выдачи. Для Recall@30, Hit@1, Hit@5 и MRR@5 основной порог — оценка ≥1, строгий — только 2. Recall делится на число **известных** релевантных работ. MRR@5 учитывает позицию первого совпадения в топ-5. Метрики усредняются по запросам, p95 рассчитан по рангу `ceil(0,95 × n)`.

При численном подсчёте неразмеченные пары дают нулевой вклад. Подтверждённые оценки 0 и отсутствующие оценки различаются при подсчёте покрытия. Все метрики предварительные, поскольку исходная разметка выборочная и выполнена AI-ассистентом. Формулы проверены на небольших искусственных примерах с неполной разметкой, двумя порогами, ручным DCG и границами отсечения.

## 4.8A-4 — Оценка по человеческой разметке

На человеческой разметке ColBERT сохранил преимущество по nDCG, но оно стало меньше. Прирост nDCG@5 сократился с 0,2234 на AI-оценках до 0,1414, прирост nDCG@10 — с 0,2132 до 0,1565. При пороге ≥1 обе выдачи дали 37/40 попаданий в топ-5. ColBERT чаще ставил подходящую работу первой.

### Парная статистическая проверка

Сравнены A (Dense) и B (Dense + ColBERT) на одинаковых запросах. nDCG повторно вычислен из сохранённых рангов и human qrels для всех 40 пар измерений. У каждого запроса совпали состав топ-30 и порядок на позициях 31–50. По nDCG@5 проверка воспроизвела исходный bootstrap 4.8A-4. Для обеих метрик использованы 20 000 парных выборок из 40 запросов с возвращением, `xorshift32`, seed 4804 и процентильный 95% интервал с линейной интерполяцией.

В permutation test внутри каждого запроса менялись местами результаты A и B. Статистика — модуль среднего парного различия. Точный тест считает все `2^40 = 1 099 511 627 776` смен знака через суммы по двум половинам. Равенство порогу включается с допуском `10^-12` на сумме. Отдельная проверка Монте-Карло использует 1 000 000 повторений, SplitMix64 с seed 48081, те же маски знаков для обеих метрик и поправку `(b+1)/(R+1)`.
