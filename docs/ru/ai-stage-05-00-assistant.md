# 5.0 — Базовый LLM-ассистент

## 5.0-1 — Защищённый API и read-only retrieval

`POST /assistant/search` вызывает существующий Hybrid Search с фильтром `type=image`, первой страницей и максимум 20 результатами для повторной проверки. Laravel перечитывает кандидатов и их оригиналы из Media Library с основного SQL-соединения. В выдачу входят опубликованные публичные изображения, доступные текущему пользователю. Глобальный фильтр исключает заблокированные работы и авторов, отдельно проверяются `ai_indexing_enabled`, политика `ArtworkPolicy::view`, MIME и наличие исходного файла в хранилище. Публичная граница действует и для владельца, и для администратора. Порядок сохраняется, `limit` применяется после фильтрации.

### Настройки и допуск

Флаг `AI_ASSISTANT_ENABLED` по умолчанию выключен. Настройки для изолированной приёмки с Dense.

```dotenv
AI_ASSISTANT_ENABLED=true
AI_SERVICE_ENABLED=true
AI_RERANK_ENABLED=false
```

Маршрут находится в существующей веб-группе с `auth:sanctum`, проверкой сессии Jetstream, `verified` и CSRF. Дополнительный `auth:web` требует веб-сессию, поэтому одного Bearer-токена Sanctum недостаточно. У текущей модели `User` есть `hasVerifiedEmail()`, а интерфейс `MustVerifyEmail` отсутствует. Маршрут ассистента явно проверяет подтверждение, чтобы оно действовало без изменения правил других страниц. Функция подтверждения email Fortify в текущей конфигурации выключена. Для прогона нужна существующая или подготовленная в тестовой БД подтверждённая запись. После допуска действует квота 10 запросов в минуту на пользователя. [Конфигурация Fortify](../../config/fortify.php).

В Laravel ограничение 4 КиБ применяется к сырым байтам тела до разбора и аутентификации. Запросы обычного размера проходят штатную CSRF-проверку веб-группы. Маршрут требует JSON-тело и отвечает JSON с `Cache-Control: private, no-store`, включая ошибки приложения. [Веб-маршрут](../../routes/web.php) · [Подготовка запроса](../../app/Http/Middleware/PrepareAssistantSearchRequest.php) · [Допуск и квота](../../app/Http/Middleware/AuthorizeAssistantSearch.php).

### Запрос и выдача

```json
{
  "query": "Найди изображения птиц у воды",
  "limit": 10
}
```

Допускается только JSON-объект с `query` и необязательным `limit`. После trim длина строки составляет 1–500 символов. `limit` принимает целые JSON-числа от 1 до 20, значение по умолчанию — 10. Параметры URL и другие поля отклоняются.

```json
{
  "status": "ok",
  "results": [
    {
      "artwork_id": 441055,
      "title": "Bird with Pink Plumage",
      "url": "/artworks/441055"
    }
  ]
}
```

Это пример формата. Laravel формирует относительный URL через `artworks.show`. `title` берётся из актуальной строки работы и может быть `null` у записи без названия. Карточка ограничена этими тремя полями. При пустом списке возвращается `{"status":"no_results","results":[]}`. [Контроллер](../../app/Http/Controllers/AssistantSearchController.php).

### Ошибки

| Код | Условие |
| --- | --- |
| 401 | Запрос прошёл проверку CSRF, но действующей веб-сессии нет. |
| 403 | Сессия действительна, email пользователя не подтверждён. |
| 404 | Ассистент выключен для допущенного пользователя. |
| 413 | Тело превышает 4096 байт. |
| 419 | Штатная проверка CSRF веб-группы отклонила запрос. |
| 422 | Тело не JSON-объект требуемого формата, параметр имеет неверное значение или переданы лишние поля. |
| 429 | Исчерпана квота допущенного пользователя. |
| 503 | Laravel не смог подтвердить состояние источников или доступ. Ответ содержит безопасное сообщение, частичная выдача исключена. |

При отказе Dense штатный Hybrid Search продолжает поиск по LIKE. Допустимость найденных таким способом работ проверяется тем же путём. Отказ окончательной SQL-проверки, политики или проверки файла даёт 503 при ошибке самой операции. Обычный запрет политики и отсутствующий файл исключают отдельную работу. Предупреждение о сбое Dense содержит только тип исключения. Фраза пользователя и сообщение исключения исключены из общего логирования этого fallback, алгоритм поиска сохранился. [Hybrid Search](../../app/Services/Search/HybridSearchService.php).

### Реализация и проверка

- Маршрут и регистрация middleware находятся в `routes/web.php` и `bootstrap/app.php`. Флаг добавлен в `config/ai.php` и оба шаблона окружения.
- Повторное чтение, авторизация результата и краткий ответ реализованы в `AssistantSearchController`. Ошибки семантической ветки санитизируются в `HybridSearchService`.
- Целевые тесты проверяют фактический маршрут, порядок и лимиты, устаревшие права и файлы, привилегированные роли, сессию и CSRF, отказ Dense и отсутствие записи в рабочие модели, очередь и индексы. [Тесты ассистента](../../tests/Feature/AssistantSearchTest.php) · [Регрессия Hybrid Search](../../tests/Feature/HybridSearchTest.php).

Совместный прогон `AssistantSearchTest` и `HybridSearchTest` прошёл на PHP 8.5.12 и PHPUnit 12.5.42. Результат — **50 тестов, 242 утверждения**. Использовались одноразовый контейнер без сети, SQLite в памяти, HTTP-моки и временный диск Media Library. Запросы к рабочим сервисам и томам отсутствовали. Повтор прогона внутри такой же среды.

```bash
php vendor/bin/phpunit --do-not-cache-result tests/Feature/AssistantSearchTest.php tests/Feature/HybridSearchTest.php
```

### Границы этапа

Приёмка 5.0-1 использует SQLite и HTTP-моки с отключённым ColBERT. Результат отражает состояние доступа при повторном чтении, а при переходе по ссылке карточка применяет собственную проверку. Реальный прогон запросов по сохранённому корпусу относится к 5.0-3. Для 5.0-2 остаётся внутренняя операция FastAPI/Ollama, которая нормализует одну поисковую фразу или возвращает ограниченное уточнение. Контекст разговоров и ответы по источникам запланированы на 5.1.
