# 5.1 — RAG и контекст диалога

## 5.1-1 — RAG-ответы с проверяемыми источниками

### Архитектура

`POST /assistant/answer` использует исходный запрос для одного Hybrid Search. `/assistant/search` и `/assistant/answer` используют общую проверку результатов. Laravel перечитывает работы из основного MySQL, проверяет публикацию, публичность, блокировки работы и автора, право просмотра, разрешение AI-индексации и наличие оригинального изображения. Нормализатор 5.0-2 в цепочку RAG не входит. Поведение `/assistant/search` сохранено. [Общий поиск](../../app/Services/Search/AssistantArtworkSearch.php) · [Контроллер ответа](../../app/Http/Controllers/AssistantAnswerController.php).

Laravel формирует ограниченный список фактов и один раз вызывает FastAPI. Модель выбирает только пары ссылок на переданные факты. Laravel проверяет список независимо от FastAPI. После вызова модельного сервиса он снова перечитывает кандидатов и сверяет снимки выбранных работ и фактов. Итоговый текст собирает Laravel по коротким шаблонам, а ссылки создаёт именованный маршрут `artworks.show`. Ссылки и ранжирование не взяты из ответа модели. [Подготовка контекста](../../app/Services/AiService/AssistantRagContext.php) · [Проверка плана](../../app/Services/AiService/AssistantAnswerComposer.php).

### Пользовательский API

`POST /assistant/answer` принимает JSON с единственным обязательным полем `query` длиной 1–500 символов после обрезки пробелов. Необязательное целое `limit` принимает значения 1–20, по умолчанию 10. Сессия Sanctum и веб-guard, подтверждённый email и CSRF действуют как в 5.0. Тело ограничено 4 КиБ. Оба маршрута расходуют общую квоту 10 запросов в минуту на пользователя. Ответы имеют `Cache-Control: private, no-store`. Для нового маршрута обязательны `AI_ASSISTANT_ENABLED` и `AI_ASSISTANT_RAG_ENABLED`. Флаг RAG по умолчанию выключен. [Правила ввода](../../app/Http/Requests/AssistantArtworkRequest.php) · [Допуск и квота](../../app/Http/Middleware/AuthorizeAssistantSearch.php).

```json
{"query":"Найди изображения птиц у воды","limit":10}
```

Пример ответа. Временные ссылки действуют только в рамках одного ответа.

```json
{
  "status": "ok",
  "answer": [
    {"source_ref":"s1","fact_ref":"f1","text":"Найдена работа «Bird with Pink Plumage»."}
  ],
  "sources": [
    {"source_ref":"s1","artwork_id":441055,"title":"Bird with Pink Plumage","url":"/artworks/441055"}
  ]
}
```

| Статус | Содержимое |
| --- | --- |
| `ok` | До пяти подтверждённых фрагментов. Каждый ссылается на источник. Карточки цитируемых работ сохранены в порядке Hybrid Search, фрагменты следуют валидированному плану. |
| `insufficient_evidence` | Пустой `answer` и доступные карточки. Модель указала, что фактов мало, либо Laravel не смог упаковать факты в бюджет. При пустом контексте вызова модели нет. |
| `search_fallback` | Пустой `answer` и повторно проверенные карточки при отказе модели, невалидном плане либо изменении выбранного факта, работы или доступа во время генерации. |
| `no_results` | Пустые `answer` и `sources`, когда доступных кандидатов нет либо они исчезли к моменту повторной проверки. |

Сетевой сбой генерации сохраняет HTTP 200 с безопасным результатом поиска. Неопределённая ошибка чтения источников или проверки права возвращает HTTP 503 без частичного ответа. Приватные, удалённые и недоступные работы отсутствуют и в fallback. Изменившаяся работа, которая осталась публичной, может быть возвращена как новая карточка без цитаты старого факта. Повторный поиск для fallback не выполняется. Остальные коды веб-маршрута соответствуют 5.0. [Ошибки поиска](ai-stage-05-00-assistant.md#ошибки).

### Факты и бюджет

В контекст входят до пяти первых доступных изображений, но не больше запрошенного `limit`. На источник приходится до семи фактов. Сначала добавляются названия разных работ, затем описания, авторы из публичной атрибуции и доступные AI-поля. Перед отправкой значения приводятся к обычному тексту, URL из значений удаляются, длина каждого значения ограничена 240 байтами UTF-8. Темы, объекты и AI-теги представлены короткими списками до четырёх строковых элементов каждый.

| Ссылки | Происхождение | Что цитируется |
| --- | --- | --- |
| `f1`, `f2` | `user_metadata` | Название и фрагмент опубликованного описания. |
| `f7` | `user_metadata` | `creator_name` из публичной атрибуции импорта, если поле заполнено. Формулировка указывает происхождение имени. |
| `f3`–`f6` | `ai_analysis` | AI-summary, темы, объекты и теги. В тексте явно указано, что сведения получены из AI-анализа. |

AI-факты допускаются при статусе `indexed` и совпадении `content_hash` текущей ревизии и UUID исходного медиа. Используется тот же расчёт ревизии, что и при Dense-индексации. При повторной проверке сверяются ревизия и значения снимка источника. Набор ограничен полями таблицы выше. Сформированные Laravel ID, URL публикаций и файлов, учётные данные, полные объекты Eloquent и исходные данные импорта в контекст не передаются.

FastAPI повторно ограничивает JSON с запросом и фактами 1400 байтами. Для `qwen3:8b` фиксированный Qwen3-шаблон передаётся в Ollama `/api/generate` в режиме `raw`. Проверка полного UTF-8 промпта вместе с инструкциями и резервом на служебные токены задаёт консервативную верхнюю границу 2048 токенов для байтового BPE этой модели. Незнакомая модель приводит к fallback. Символы разметки в пользовательском JSON экранируются, чтобы вход не мог добавить управляющие маркеры Qwen. Недоверенные текстовые поля остаются данными. `num_ctx=2304`, `num_predict=256`, `temperature=0`, `think=false`. Оборванная генерация и превышение числа токенов, если Ollama сообщил счётчики, отклоняются. [Операция Ollama](../../ai-service/app/clients/ollama.py).

### Внутренний API

`POST /api/v1/assistant/compose` принимает ключ `X-AI-Service-Key` и требует оба флага ассистента и RAG. Флаг нормализации `AI_ASSISTANT_LLM_ENABLED` для него не требуется. Запрос содержит фразу и плоский список фактов. Лишние поля, неизвестные значения, повторы пар и превышение ограничений отклоняются схемой. [Маршрут](../../ai-service/app/api/routes.py) · [Схемы](../../ai-service/app/schemas/assistant.py).

```json
{"query":"Найди изображения птиц у воды","facts":[{"source_ref":"s1","fact_ref":"f1","value":"Bird with Pink Plumage","origin":"user_metadata"}]}
```

```json
{"action":"compose","selections":[{"source_ref":"s1","fact_ref":"f1"}]}
```

Второй допустимый план — `{"action":"insufficient_evidence","selections":[]}`. Состав плана ограничен выбранными парами, без произвольного текста, URL и ID публикаций. Таймауты используют существующие `AI_ASSISTANT_LLM_TIMEOUT` (15 с) и `OLLAMA_ASSISTANT_TIMEOUT` (12 с). HTTP-вызовы не повторяются. FastAPI отвечает 401 при проблеме с ключом, 404 при выключенном флаге, 422 при неверном входе или бюджете, 502 при ошибке или неверном плане Ollama и 504 при таймауте. Логи содержат только категорию отказа или тип исключения.

### Проверки и ограничения

Целевые наборы `AssistantAnswerTest`, `AssistantSearchTest` и `HybridSearchTest` прошли на SQLite с HTTP-моками. Результат — 92 теста и 503 утверждения. Проверены авторизация, квота, CSRF, доступ и порядок карточек, ревизии, отзыв доступа, подмена плана, fallback и отсутствие записей в очередь и индексы. Прогон Python TestClient и HTTP-моков прошёл 113 тестов, включая регрессии нормализации, Ollama, авторизации, FastAPI и поисковой видимости. Проверены оба флага и ключ, вход, ссылки, инъекции через поля, бюджет и генерация, таймауты и отсутствие вызовов к Qdrant. Starlette сообщил об устаревающем использовании `httpx` в TestClient. [Laravel-тесты](../../tests/Feature/AssistantAnswerTest.php) · [Python-тесты](../../ai-service/tests/test_assistant_composition.py).

Каждый фрагмент подтверждает содержание поля текущей публикации. Выбор модели не служит независимой проверкой фактической достоверности описания. Повторное чтение проверяет доступ перед выдачей. Карточка применяет свою проверку при переходе, поскольку доступ может измениться уже после ответа. Существующее ограничение `/ready` сохраняется. Отсутствие chat-модели снижает readiness всего FastAPI, даже если embedding отвечает. Отдельный прогон нужен, чтобы оценить это поведение в выбранном изолированном контуре. [Наблюдение 5.0-3](ai-stage-05-00-assistant.md#50-3--сквозная-проверка-llm-ассистента).

Реальные результаты на копии 4.4C приведены ниже. Диалоговая память остаётся в 5.1-2. [Дорожная карта](ai-roadmap-v5.md#51--rag-и-контекст-диалога).

## 5.1-1R — Реальная интеграционная проверка RAG

### Контур и методика

Использован остановленный контур `library-stroll-50-assistant` с четырьмя сохранёнными томами 5.0-3. Перед запросами подтверждены 100 работ `indexed`, 100 точек Qdrant размерности 1024, совпадение ID и хешей, а также SHA-256 всех оригиналов Media Library. Контрольный снимок совпал с 5.0-3. Laravel и FastAPI использовали исходники ветки `docker` на коммите `80785d7` через монтирования только для чтения. Контур работал без опубликованных портов, workers, планировщика и ColBERT. В обоих сервисах включены флаги ассистента и RAG. Нормализация выключена. Таймауты сохранены на 15 с в Laravel и 12 с для Ollama. [Контур 5.0-3](ai-stage-05-00-assistant.md#50-3--сквозная-проверка-llm-ассистента) · [Архив корпуса](ai-stage-04-04-dataset.md#44c--100-изображений).

Запросы прошли через Nginx, реальную подтверждённую веб-сессию и CSRF. Наблюдатели в тестовом Compose измеряли штатные методы Laravel и реальные HTTP-вызовы. Они сохраняли длительности, статусы, ID, пары фактов, контрольные суммы значений и счётчики Ollama. В контуре использованы Windows Ollama 0.40.10, `qwen3:8b` с digest `500a1f067a9f…` и `qwen3-embedding:0.6b` с digest `ac6da0dfba84…`.

### Результаты и задержки

На запрос «Найди изображения птиц у воды» `/assistant/search` вернул HTTP 200 и 10 карточек в порядке `441055, 441058, 441031, 441056, 441080, 441033, 441066, 441030, 441006, 441081`. В каждом запросе наблюдались один Hybrid Search, одно вычисление embedding и один вызов Qdrant. Qdrant вернул 50 кандидатов. Hybrid Search передал первые 20 из 50, и все 20 прошли проверку доступности в рамках данного прогона. Порядок кандидатов исходного RU-запроса совпал между `/assistant/search`, RAG и fallback. RAG ограничил контекст пятью работами, а в `sources` вернул только процитированные работы или безопасную выдачу при fallback.

Единственный диагностический повтор того же запроса вернул `compose` с повтором пары фактов. FastAPI снова отклонил план, а Laravel вернул проверенные карточки. Широкий запрос получил пять названий вместо `insufficient_evidence`. Вызова нормализатора не было ни в одном из девяти запросов.

RAM Windows изменилась с 16 268 до 17 345 МиБ из 32 690 МиБ. Это снимки ресурсов, пиковые значения и процентили не измерялись.

### Достоверность и полезность

Для всех 25 выданных фрагментов совпали пара `source_ref/fact_ref`, происхождение и SHA-256 значения в переданном контексте и актуальном снимке Laravel. Каждый цитируемый URL открывал ту же публикацию с HTTP 200. Сверка объясняет происхождение каждого фрагмента. Содержание публичного поля и вывод модели имеют разные основания доверия.

- **Основной RU.** Холодный, прогретый и восстановленный запросы выбрали одинаковые пары `s1/f1`, `s1/f2`, `s3/f1`, `s3/f2`, `s5/f1`. Источники — `441055`, `441031` и `441080`. На фото `441055` птица стоит у тёмной воды, на `441031` птицы изображены над волнами. Выбранные названия и описание птицы полезны частично, вода в выбранных полях не названа. Сведения об авторе, периоде и технике `441031` не объясняют релевантность. У птицы на ветке `441080` водоём не виден.
- **Конкретный EN.** Запрос `A bright pink bird with a flattened spoon-shaped bill beside dark water` выбрал `s1/f1`, `s1/f2`, `s5/f1`, `s4/f2` и `s1/f4`. Описание `441055` подтверждает розовое оперение и сплющенный клюв. Тёмная вода подтверждается оригиналом, но в выбранном описании её нет. Белый гусь `441033` и птица в натюрморте `441066` не соответствуют конкретным визуальным признакам запроса. AI-темы `441055` слишком общие и сохранены с явной отметкой происхождения.
- **Широкий RU.** Модель выбрала названия пяти работ. Фрагменты совпали с карточками, но запрос не задаёт признаков, по которым можно объяснить выбор.

### Отказ, безопасность и целостность

В B изменён только `OLLAMA_CHAT_MODEL` изолированного FastAPI на отсутствующий тег. Существующая проверка модели для бюджета RAG отклонила эту конфигурацию до вызова `/api/generate`. На реальном маршруте FastAPI ответил 502, Laravel вернул пустой `answer` и те же десять карточек в прежнем порядке. Embedding и Qdrant отработали. Общий `/ready` вернул 503. Оркестратор, который исключает контейнер по этому сигналу, может лишить Laravel и доступного Dense Search. После возврата `qwen3:8b` readiness восстановился и RAG снова вернул пять фрагментов.

Гость с CSRF получил 401, запрос с сессией без CSRF — 419, внутренний compose без ключа — 401. Временная приватная работа с заголовком, совпадающим с RU-запросом, отсутствовала в контексте и источниках. Открытие её карточки вернуло 403. Ответы содержали только канонические ссылки на карточки. В проверенных журналах тестовых сервисов и выборке журнала Ollama фразы не обнаружены. В логах тестового контура общий ключ отсутствовал. Промпты и сырые ответы модели не сохранялись.

Снимки публикаций, AI-метаданных, истории обработки, Media Library и всех точек Qdrant до и после совпали. SHA-256 снимков — `401785cbd35f0c3e68e5c33b5d2d2db56472b96a8b01f3349fe7e51a5601b0e0`. Контрольные суммы 4.4C сохранились, очередь Redis осталась пустой. Служебные изменения учтены отдельно. В тестовой БД обновлялся пароль существующей тестовой записи, создавалась и удалялась приватная работа, 13 счётчиков просмотров и затронутые даты восстановлены после реальных открытий карточек. Сессии и счётчики квоты обновлялись штатно.

### Артефакты

В `storage/app/ai-stage-05-01/5.1-1r/` сохранены `summary.json`, `latency.json`, `selections.json`, `integrity.json`, `environment.json` и `shutdown.json`, а также измерения и локальные сценарии прогона. Шесть тестовых контейнеров остановлены, четыре тома сохранены. Код приложения, промпт и ранжирование остались прежними. Реальная цепочка RAG и fallback подтверждены. Надёжность выбора релевантных и уникальных пар ограничена наблюдаемыми ошибками модели. Этап 5.1 остаётся открытым.

## 5.1-2A — Хранение и защита истории диалогов

### Данные

| Таблица | Содержимое и ограничения |
| --- | --- |
| `assistant_conversations` | UUID, `user_id` владельца и даты. Индекс по владельцу, дате активности и UUID поддерживает порядок списка. Удаление аккаунта каскадно удаляет его диалоги. |
| `assistant_turns` | UUID, UUID диалога, уникальный в рамках диалога номер `sequence`, собственный запрос пользователя, статус обработки, запрошенный лимит, внутренние ссылки на факты и даты. Удаление диалога каскадно удаляет ходы. |

Laravel шифрует `user_query` при записи через encrypted cast и ключ приложения. Поле хранится как `TEXT`, чтобы вместить шифротекст. Оно скрыто при обычной сериализации модели. Только API принадлежащего пользователю диалога явно возвращает расшифрованный запрос. Ссылки хранятся в JSON и также скрыты при сериализации. Запись ссылки содержит `artwork_id`, стабильный код поля `fact_ref`, `revision_hash` работы и `fact_sha256` значения. Второй хеш позволяет выявить замену факта без изменения Dense-ревизии. Временные ссылки RAG, исходные тексты публикаций, готовые ответы, промпты, векторы и URL файлов в схеме отсутствуют. [Миграция](../../database/migrations/2026_11_23_100000_create_assistant_history_tables.php) · [Модель хода](../../app/Models/AssistantTurn.php).

Внутренний метод записи хода проверяет владельца, поля, ссылки и лимиты. В транзакции он блокирует строку диалога, назначает следующий номер хода и обновляет дату активности. Создание диалога проверяет квоту под блокировкой строки владельца. Ограничения внешних ключей и уникальный индекс действуют на уровне базы. API поиска и RAG на этом этапе не вызывают запись. [Сервис истории](../../app/Services/Search/AssistantConversationHistory.php).

### API

Все маршруты возвращают JSON, кроме успешного удаления с пустым телом. Ответы используют `Cache-Control: private, no-store`. Применяются Sanctum и действующая веб-сессия, подтверждённый email и CSRF для POST и DELETE. Запросы с телом свыше 4 КиБ получают 413. Флаг `AI_ASSISTANT_HISTORY_ENABLED=false` закрывает все четыре маршрута. Для создания диалога требуется также `AI_ASSISTANT_ENABLED=true`. При отключении основного ассистента включённая история остаётся доступна владельцу для чтения и удаления. [Маршруты](../../routes/web.php) · [Допуск](../../app/Http/Middleware/AuthorizeAssistantSearch.php).

| Запрос | Ответ |
| --- | --- |
| `POST /assistant/conversations` | 201 и `conversation` с ID и датами. Владелец берётся из сессии, тело запроса не задаёт поля диалога. При исчерпании лимита возвращается 409. |

Пагинация принимает `page` от 1 до 1000 и `per_page` от 1 до настроенного размера. Поля `pagination` включают `page`, `per_page` и `has_more`. ## 5.1-2B — Сохранение RAG-ходов и контекстные уточнения

### API и сохранение

`POST /assistant/conversations/{conversation}/turns` принимает JSON `{"query":"Найди изображения птиц у воды","limit":10}` и возвращает HTTP 201 с `turn_id`, `sequence`, `status`, `answer` и `sources`. Статусы `ok`, `search_fallback`, `no_results`, `insufficient_evidence` и `clarification_required` сохраняются как результаты обработанного хода. Тело запроса может содержать только фразу и лимит. Ссылки, история и параметры доступа определяются сервером. Маршрут проверяет веб-сессию, подтверждённый email, CSRF и владельца. Он разделяет квоту 10 запросов в минуту с `/assistant/search` и `/assistant/answer`. GET и DELETE истории этой квотой не ограничены. Существующие маршруты поиска и ответа используют прежние контракты и работают вне истории. [Маршруты](../../routes/web.php) · [Обработка хода](../../app/Http/Controllers/AssistantTurnController.php).

Общая RAG-обработка формирует факты и карточки и повторно проверяет источники после генерации. `appendTurn()` записывает зашифрованный пользовательский запрос, статус, запрошенный лимит и только выбранные подтверждённые ссылки. Каждая ссылка содержит `artwork_id`, `fact_ref`, `revision_hash` и `fact_sha256`. Статусы без цитат сохраняют пустой список. Тексты ответов, карточки fallback, сырые результаты Qdrant и временные ссылки не сохраняются. [RAG-сервис](../../app/Services/Search/AssistantRagAnswer.php) · [Запись истории](../../app/Services/Search/AssistantConversationHistory.php).

Перед вызовами модели Laravel проверяет доступ и свободный слот и фиксирует номер последнего хода. Resolver и composer работают вне транзакции. При записи Laravel под блокировкой строки диалога сверяет владельца и номер, затем проверяет возвращаемые источники из основной базы и сохраняет ход атомарно. Если другой запрос уже записал ход или источники изменились до записи, ответ 409 не содержит непроверенных карточек. Если диалог удалён или сменился владелец, возвращается 404. Ошибка проверки данных даёт 503 без записи. Последовательный повтор запроса считается новым ходом. Внешнее медиа и доступ после завершения транзакции могут измениться, поэтому чтение истории и переход по ссылкам повторно проверяют состояние.

### История и контекст

GET диалога сохраняет поля 5.1-2A и добавляет каждому ходу `answer`, `sources` и `source_status`.

| `source_status` | Значение |
| --- | --- |
| `none` | Подтверждённые ссылки при записи отсутствовали. |
| `available` | Восстановлены все сохранённые факты. |
| `partial` | Восстановлена часть сохранённых фактов. |
| `unavailable` | Ни один сохранённый факт не прошёл текущую проверку. |

Работы на странице истории загружаются одним запросом, а метаданные, теги и медиа — отдельными пакетными запросами. Каждый факт требует подтверждения публичности, политики просмотра, наличия файла, ревизии и хеша текущего значения. При отзыве доступа, удалении, блокировке или смене значения исчезают цитата и карточка, если у неё больше нет подтверждённых цитат. `result_status` остаётся историческим. Текст и ссылки собираются заново. GET не вызывает Dense Search, FastAPI или запись в индексы. [Повторная проверка](../../app/Services/Search/AssistantSavedSources.php).

Resolver получает текущую фразу, до четырёх последних собственных запросов и проверенные факты до пяти изображений. Сначала отбираются факты из последних ходов, затем текст сообщений в пределах оставшегося бюджета. Сообщения служат контекстом разговора, а не подтверждением свойств изображений. После выбора прежних работ Laravel ещё раз проверяет ссылки и передаёт в composer только разрешённые факты выбранной группы. Hybrid Search для этого уточнения не запускается. [Подготовка контекста](../../app/Services/Search/AssistantTurnContext.php).

Для уточнения о дате поддерживаются явно записанные в ранее процитированном публичном описании год или один век в поле `Date:` или `Дата:`. Например, `Date: 1851.` подходит для XIX века. Название, AI-анализ, приблизительная дата и запись `18th–19th century` не подтверждают принадлежность к одному веку. Без подходящего факта Laravel возвращает `insufficient_evidence` без объяснения о периоде. Поддержка языковых формулировок ограничена, в том числе для диапазонов и отрицаний. [Проверка дат](../../app/Services/Search/AssistantPreviousDates.php).

### Внутренний resolver

`POST /api/v1/assistant/resolve-followup` принимает `query`, `previous_queries` и `facts` по строгой схеме. JSON ограничен 1400 байтами, полный ввод — 2048 токенами вместе с инструкциями, генерация — 256 токенами. Операция использует установленный `qwen3:8b`, `temperature=0`, `think=false` и существующий raw-шаблон. Входные поля остаются данными, управляющие маркеры экранируются. Ответ содержит исключительно `action` и список `source_refs`. [FastAPI](../../ai-service/app/api/routes.py) · [Схемы](../../ai-service/app/schemas/assistant.py).

- `new_search` возвращает пустой список и использует исходную фразу для одного обычного поиска.
- `use_previous` выбирает непустой список уникальных источников, переданных Laravel.
- `clarify` возвращает пустой список, когда данных для уточнения недостаточно.

FastAPI требует сервисный ключ и флаги ассистента, RAG и контекста. Laravel независимо проверяет действие и ссылки. Невалидный план даёт уточнение. При недоступности resolver, выключенном контексте или недостатке места в бюджете независимый поиск допустим только при явной самостоятельной формулировке. Ссылка на отсутствующий контекст, например «из них», не расширяет поиск на каталог. Первый самостоятельный запрос сразу идёт в обычный RAG.

`AI_ASSISTANT_CONTEXT_ENABLED` по умолчанию выключен и управляет только resolver. Для записи хода нужны `AI_ASSISTANT_ENABLED`, `AI_ASSISTANT_RAG_ENABLED` и `AI_ASSISTANT_HISTORY_ENABLED` в Laravel. Чтение и удаление зависят от доступа к истории и работают при остановленном Ollama. Каждый HTTP-вызов сохраняет отдельный таймаут без повтора, 15 с со стороны Laravel и 12 с со стороны FastAPI → Ollama по умолчанию. Раздельные события debug содержат длительность операций без текстов, ключей и содержимого ответа.

### Проверки и 5.1-2R

Основной прогон Laravel на SQLite с HTTP-моками прошёл 144 теста и 991 утверждение. Отдельный тест последовательного повтора добавил ещё один успешный тест и девять утверждений. Проверены сохранение только подтверждённых ссылок, шифрование, разделение независимого и контекстного поиска, отзыв прав, смена значения при прежней ревизии, чтение страницы одним пакетом и удаление. Конкурентная запись проверена имитацией перекрывающихся запросов в точке генерации. Python TestClient прошёл 150 тестов с регрессиями FastAPI. Тесты resolver покрывают строгие схемы, русские и английские запросы, неизвестные ссылки, бюджеты, таймауты и инъекции через контекст. [Laravel](../../tests/Feature/AssistantTurnTest.php) · [Python](../../ai-service/tests/test_assistant_followup.py).

Для 5.1-2R потребуется изолированная копия корпуса, MySQL с миграцией истории из 5.1-2A, Qdrant, установленный `qwen3:8b`, действующая веб-сессия и общий сервисный ключ. Следует проверить реальный RAG на первом ходе, уточнение с достаточным и недостаточным подтверждением даты, независимый следующий запрос, отзыв доступа и отсутствие изменений индексов. Измерения resolver и composer ведутся отдельно. Качество выбора фактов остаётся предметом 5.4.

## 5.1-2R — Реальная интеграционная проверка многоходового диалога

**Результат приёмки.** На реальных сервисах подтверждены первый RAG-ход, хранение и восстановление проверенных цитат, безопасное уточнение при отсутствии даты, независимый поиск, отзыв доступа, fallback и удаление истории. Обязательный сценарий C2 с подтверждённой датой не прошёл. Resolver не выбрал `use_previous`, поэтому положительный ответ о XIX веке в рамках разрешённой истории не подтверждён. 5.1-2R и этап 5.1 остаются открытыми.
