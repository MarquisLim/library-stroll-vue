# 5.1 — RAG и контекст диалога

## 5.1-1 — RAG-ответы с проверяемыми источниками

### Архитектура

`POST /assistant/answer` использует исходный запрос для одного Hybrid Search. `/assistant/search` и `/assistant/answer` используют общую проверку результатов. Laravel перечитывает работы из основного MySQL, проверяет публикацию, публичность, блокировки работы и автора, право просмотра, разрешение AI-индексации и наличие оригинального изображения. Нормализатор 5.0-2 в цепочку RAG не входит. Поведение `/assistant/search` сохранено. [Общий поиск](../../app/Services/Search/AssistantArtworkSearch.php) · [Контроллер ответа](../../app/Http/Controllers/AssistantAnswerController.php).

Laravel формирует ограниченный список фактов и один раз вызывает FastAPI. Модель выбирает только пары ссылок на переданные факты. Laravel проверяет список независимо от FastAPI. После вызова модельного сервиса он снова перечитывает кандидатов и сверяет снимки выбранных работ и фактов. Итоговый текст собирает Laravel по коротким шаблонам, а ссылки создаёт именованный маршрут `artworks.show`. Ссылки и ранжирование не взяты из ответа модели. [Подготовка контекста](../../app/Services/AiService/AssistantRagContext.php) · [Проверка плана](../../app/Services/AiService/AssistantAnswerComposer.php).

### Пользовательский API

`POST /assistant/answer` принимает JSON с единственным обязательным полем `query` длиной 1–500 символов после обрезки пробелов. Необязательное целое `limit` принимает значения 1–20, по умолчанию 10. Сессия Sanctum и веб-guard, подтверждённый email и CSRF действуют как в 5.0. Тело ограничено 4 КиБ. Оба маршрута расходуют общую квоту 10 запросов в минуту на пользователя. Ответы имеют `Cache-Control: private, no-store`. Для нового маршрута обязательны `AI_ASSISTANT_ENABLED` и `AI_ASSISTANT_RAG_ENABLED`. Флаг RAG по умолчанию выключен. [Правила ввода](../../app/Http/Requests/AssistantArtworkRequest.php) · [Допуск и квота](../../app/Http/Middleware/AuthorizeAssistantSearch.php).

```json
{"query":"Найди изображения птиц у воды","limit":10}
```

Пример ответа. Временные ссылки действуют только в рамках одного ответа.

```json
{
  "status": "ok",
  "answer": [
    {"source_ref":"s1","fact_ref":"f1","text":"Найдена работа «Bird with Pink Plumage»."}
  ],
  "sources": [
    {"source_ref":"s1","artwork_id":441055,"title":"Bird with Pink Plumage","url":"/artworks/441055"}
  ]
}
```

| Статус | Содержимое |
| --- | --- |
| `ok` | До пяти подтверждённых фрагментов. Каждый ссылается на источник. Карточки цитируемых работ сохранены в порядке Hybrid Search, фрагменты следуют валидированному плану. |
| `insufficient_evidence` | Пустой `answer` и доступные карточки. Модель указала, что фактов мало, либо Laravel не смог упаковать факты в бюджет. При пустом контексте вызова модели нет. |
| `search_fallback` | Пустой `answer` и повторно проверенные карточки при отказе модели, невалидном плане либо изменении выбранного факта, работы или доступа во время генерации. |
| `no_results` | Пустые `answer` и `sources`, когда доступных кандидатов нет либо они исчезли к моменту повторной проверки. |

Сетевой сбой генерации сохраняет HTTP 200 с безопасным результатом поиска. Неопределённая ошибка чтения источников или проверки права возвращает HTTP 503 без частичного ответа. Приватные, удалённые и недоступные работы отсутствуют и в fallback. Изменившаяся работа, которая осталась публичной, может быть возвращена как новая карточка без цитаты старого факта. Повторный поиск для fallback не выполняется. Остальные коды веб-маршрута соответствуют 5.0. [Ошибки поиска](ai-stage-05-00-assistant.md#ошибки).

### Факты и бюджет

В контекст входят до пяти первых доступных изображений, но не больше запрошенного `limit`. На источник приходится до семи фактов. Сначала добавляются названия разных работ, затем описания, авторы из публичной атрибуции и доступные AI-поля. Перед отправкой значения приводятся к обычному тексту, URL из значений удаляются, длина каждого значения ограничена 240 байтами UTF-8. Темы, объекты и AI-теги представлены короткими списками до четырёх строковых элементов каждый.

| Ссылки | Происхождение | Что цитируется |
| --- | --- | --- |
| `f1`, `f2` | `user_metadata` | Название и фрагмент опубликованного описания. |
| `f7` | `user_metadata` | `creator_name` из публичной атрибуции импорта, если поле заполнено. Формулировка указывает происхождение имени. |
| `f3`–`f6` | `ai_analysis` | AI-summary, темы, объекты и теги. В тексте явно указано, что сведения получены из AI-анализа. |

AI-факты допускаются при статусе `indexed` и совпадении `content_hash` текущей ревизии и UUID исходного медиа. Используется тот же расчёт ревизии, что и при Dense-индексации. При повторной проверке сверяются ревизия и значения снимка источника. Набор ограничен полями таблицы выше. Сформированные Laravel ID, URL публикаций и файлов, учётные данные, полные объекты Eloquent и исходные данные импорта в контекст не передаются.

FastAPI повторно ограничивает JSON с запросом и фактами 1400 байтами. Для `qwen3:8b` фиксированный Qwen3-шаблон передаётся в Ollama `/api/generate` в режиме `raw`. Проверка полного UTF-8 промпта вместе с инструкциями и резервом на служебные токены задаёт консервативную верхнюю границу 2048 токенов для байтового BPE этой модели. Незнакомая модель приводит к fallback. Символы разметки в пользовательском JSON экранируются, чтобы вход не мог добавить управляющие маркеры Qwen. Недоверенные текстовые поля остаются данными. `num_ctx=2304`, `num_predict=256`, `temperature=0`, `think=false`. Оборванная генерация и превышение числа токенов, если Ollama сообщил счётчики, отклоняются. [Операция Ollama](../../ai-service/app/clients/ollama.py).

### Внутренний API

`POST /api/v1/assistant/compose` принимает ключ `X-AI-Service-Key` и требует оба флага ассистента и RAG. Флаг нормализации `AI_ASSISTANT_LLM_ENABLED` для него не требуется. Запрос содержит фразу и плоский список фактов. Лишние поля, неизвестные значения, повторы пар и превышение ограничений отклоняются схемой. [Маршрут](../../ai-service/app/api/routes.py) · [Схемы](../../ai-service/app/schemas/assistant.py).

```json
{"query":"Найди изображения птиц у воды","facts":[{"source_ref":"s1","fact_ref":"f1","value":"Bird with Pink Plumage","origin":"user_metadata"}]}
```

```json
{"action":"compose","selections":[{"source_ref":"s1","fact_ref":"f1"}]}
```

Второй допустимый план — `{"action":"insufficient_evidence","selections":[]}`. Состав плана ограничен выбранными парами, без произвольного текста, URL и ID публикаций. Таймауты используют существующие `AI_ASSISTANT_LLM_TIMEOUT` (15 с) и `OLLAMA_ASSISTANT_TIMEOUT` (12 с). HTTP-вызовы не повторяются. FastAPI отвечает 401 при проблеме с ключом, 404 при выключенном флаге, 422 при неверном входе или бюджете, 502 при ошибке или неверном плане Ollama и 504 при таймауте. Логи содержат только категорию отказа или тип исключения.

### Проверки и ограничения

Целевые наборы `AssistantAnswerTest`, `AssistantSearchTest` и `HybridSearchTest` прошли на SQLite с HTTP-моками. Результат — 92 теста и 503 утверждения. Проверены авторизация, квота, CSRF, доступ и порядок карточек, ревизии, отзыв доступа, подмена плана, fallback и отсутствие записей в очередь и индексы. Прогон Python TestClient и HTTP-моков прошёл 113 тестов, включая регрессии нормализации, Ollama, авторизации, FastAPI и поисковой видимости. Проверены оба флага и ключ, вход, ссылки, инъекции через поля, бюджет и генерация, таймауты и отсутствие вызовов к Qdrant. Starlette сообщил об устаревающем использовании `httpx` в TestClient. [Laravel-тесты](../../tests/Feature/AssistantAnswerTest.php) · [Python-тесты](../../ai-service/tests/test_assistant_composition.py).

Каждый фрагмент подтверждает содержание поля текущей публикации. Выбор модели не служит независимой проверкой фактической достоверности описания. Повторное чтение проверяет доступ перед выдачей. Карточка применяет свою проверку при переходе, поскольку доступ может измениться уже после ответа. Существующее ограничение `/ready` сохраняется. Отсутствие chat-модели снижает readiness всего FastAPI, даже если embedding отвечает. Отдельный прогон нужен, чтобы оценить это поведение в выбранном изолированном контуре. [Наблюдение 5.0-3](ai-stage-05-00-assistant.md#50-3--сквозная-проверка-llm-ассистента).

Для реального прогона нужна проверенная копия 100 работ 4.4C, внутренняя сеть FastAPI, подтверждённая веб-сессия и CSRF, общий непустой ключ и установленные `qwen3:8b` и `qwen3-embedding:0.6b`. В Laravel и FastAPI включаются оба флага ассистента и RAG, ColBERT остаётся выключенным. Следует измерить холодный и прогретый вызов, проверить реальные выборы фактов и fallback с сохранением Dense Search и сверить целостность копий до и после. Моки подтверждают контракт и обработку отказов. Реальная генерация RAG относится к отдельной проверке. Диалоговая память остаётся в 5.1-2. [Дорожная карта](ai-roadmap-v5.md#51--rag-и-контекст-диалога).
