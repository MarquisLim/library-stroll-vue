# 4.6A — LIKE и MySQL FULLTEXT

На прежних 24 смысловых запросах оба варианта FULLTEXT чаще находили английские слова, но снижали MRR@5 гибридного поиска. На восьми новых лексических запросах оба подняли одну цель со второго места на первое, сохранив Hit@5. На этой выборке оснований заменять LIKE в текущем RRF нет.

## Методика

В изолированном проекте `library-stroll-44-dataset` проверены 100 публичных работ тестового автора, ID `441001–441100`. Скрипт применил `Artwork::publiclyVisible()` со штатным исключением заблокированных работ и авторов. В отдельную таблицу InnoDB скопированы ID, исходные `title` и `description`, а также счётчик лайков. AI-summary и теги отсутствовали в копии. MySQL 8.4.13 использовал исходную колляцию `utf8mb4_unicode_ci`, стандартный парсер, токены длиной 3–84 символа и включённый штатный список стоп-слов.

| Вариант | Условие и порядок |
| --- | --- |
| A | `title LIKE '%query%'`, по убыванию числа лайков |
| B | `FULLTEXT(title)`, `MATCH(title) AGAINST (... IN NATURAL LANGUAGE MODE)` |
| C | `FULLTEXT(title, description)`, `MATCH(title, description) AGAINST (... IN NATURAL LANGUAGE MODE)` |

B и C сортируют по убыванию оценки MySQL и по ID при равной оценке. Выдача A на копии сверена с запросом Laravel к исходным таблицам на всех 32 запросах, включая порядок. Метрики рассчитаны по всем запросам группы. В MRR@5 цель за пределами топ-5 или вне выдачи даёт ноль.

Первые 24 запроса и ожидаемые ID совпадают с 4.5A. Для них взят топ-50 из сохранённой Dense-выдачи 4.4C. Его первые 30 ID и оценки сверены с 4.5A. Для новых запросов Dense топ-50 получен один раз через изолированный FastAPI с той же `qwen3-embedding:0.6b` и тем же автором. Оба набора заморожены до лексического прогона. Использован штатный `ReciprocalRankFusion` с лимитами 50 лексических и 50 Dense-кандидатов, `rrf_k=60` и максимумом 100 результатов. ColBERT выключен. Полный порядок контрольного Hybrid A на прежних 24 запросах совпал с 4.5B-2.

SQL-задержка включает подготовку запроса, обращение к MySQL и получение строк. Для каждого запроса выполнены один прогрев и 20 замеров каждого варианта с чередованием порядка. p95 рассчитан по рангу `ceil(0,95 × число замеров)`. Задержки относятся к нагрузке одного клиента на копии из 100 строк. Время эмбеддинга, поискового HTTP, загрузки моделей и рендеринга страницы в замеры не входит.

## Ограничения и воспроизведение

В исходных данных кириллицы нет ни в одном названии или описании. Среди 16 русских формулировок единственную лексическую выдачу дал вариант C по латинскому имени Nadar. Результат показывает ограничение межъязыкового буквального поиска на этом корпусе. Он не измеряет качество FULLTEXT на русскоязычных документах или обработку русских словоформ. Стандартный MySQL FULLTEXT ищет токены в сохранённом тексте. Длина токена, стоп-слова и колляция влияют на совпадения. [Режим Natural Language](https://dev.mysql.com/doc/refman/8.4/en/fulltext-natural-language.html), [настройки FULLTEXT](https://dev.mysql.com/doc/refman/8.4/en/fulltext-fine-tuning.html).

SQL-ошибок в измеренном прогоне не было. Прошли 24 целевых теста Laravel (54 утверждения) для RRF и Hybrid Search. Контрольные суммы SQL-снимка и 100 точек Qdrant совпали до и после. Таблица эксперимента удалена, тестовые сервисы остановлены, тома сохранены.

Исследовательский скрипт `scripts/research/mysql_fulltext_benchmark.php` запускается из рабочего каталога Laravel внутри `library-stroll-44-dataset-app-1`. Режим `freeze-dense` принимает план и исторический `search-100.jsonl` этапа 4.4C, запрашивает Dense только для восьми новых запросов. Режим `measure` принимает тот же план и сохранённый `dense-top50.json`. Для повтора измерения оба файла и скрипт копируются в тестовый контейнер. Скрипт проверяет имя базы и состав выборки перед созданием отдельной таблицы.

```powershell
docker exec -e AI_SERVICE_ENABLED=false -e AI_RERANK_ENABLED=false library-stroll-44-dataset-app-1 php /tmp/dataset-46a/mysql_fulltext_benchmark.php measure /tmp/dataset-46a/query-plan.json /tmp/dataset-46a/dense-top50.json
```

В `storage/app/ai-stage-04-06` сохранены `query-plan.json`, `new-query-plan.json`, `dense-top50.json`, `results.json` с сырыми замерами, `metrics.json`, `positions.json` с топ-5 и позициями целей по всем 32 запросам, `rrf-changes.json` и `integrity.json`.
