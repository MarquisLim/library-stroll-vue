В `ai_processing_runs` есть 140 попыток `analyze_and_index`. Все **24 успешные** помечены `text_fallback` с предупреждением `Vision unavailable (ValueError); analyzed text metadata instead`. Из **116 неуспешных** в 111 зарегистрировано сообщение о невозможности подключения, в 5 — таймаут. Все 21 последних ошибок MySQL относятся к подключению. ## 4. Сверка Qdrant

Точный `count` и полный `scroll` дали **20 точек** с `artwork_id` от `1` до `20`. Метрика `indexed_vectors_count=0` отображается вместе с `points_count=20`. Штатный поиск успешно читает все 20 точек.

| Проверка | Результат |
|---|---:|
| Повторные `artwork_id` / повторные UUID точек | 0 / 0 |
| Точки без публикации в MySQL / вне допустимой видимости | 0 / 0 |
| MySQL `indexed` без точки | 0, строк `indexed` сейчас нет |
| Точки действующих работ со статусом MySQL `failed` | 20 |

| Расхождения версий, размерности, `user_id`, `media_type`, `has_ai`, каталожных тегов | 0 по каждому полю |
| Расхождения `is_published`, `is_private`, `is_blocked` | 0 |
| Точек с тегом embedding-модели или fingerprint в payload | 0 |

FastAPI применяет Qdrant-фильтр `media_type=image`, `is_published=true`, `is_private=false`, `is_blocked=false`. Затем Laravel проверяет текущую видимость и `ai_indexing_enabled`, а слой ассистента дополнительно проверяет MIME и наличие оригинала. Все 20 точек прошли эти проверки. Статус метаданных Dense-фильтр не проверяет. Текущая embedding-модель возвращает 1024 компонента. Практическая совместимость также проверена повторным вычислением части векторов.

Сравнение всех 190 пар векторов дало 0 совпадений SHA-256 float32 и 0 пар с cosine ≥0,95. Самые близкие пары — `10/11` (0,865951), `4/5` (0,840971), `9/20` (0,796793). Штатный `ai:reconcile-artwork --dry-run` для `4`, `18`, `20` вернул группу B, хеш и версии совпадают, fingerprint неизвестен. Для `77` и `191` вернул группу E, AI-индексация отключена. ## 5. Searchable text

`AnalyzeAndIndexArtworkJob` объединяет через пробел в указанном порядке `title`, `description`, AI `summary`, `tags_en`, `tags_ru`, каталожные теги, `objects`, `themes`, `styles`, `mood`, `colors`. FastAPI передаёт строку в `/api/embed`. В индексе хранятся вектор, фильтруемые поля, хеш ревизии и версии. Таблица `artwork_colbert_expectations` пуста. Штатное сохранение текста там зависит от флага автоматического ColBERT sync. Исторические входные строки в проверенных хранилищах отсутствуют.

Реконструкции по текущим полям имеют 753–1276 символов. Каталожные описания содержат автора, дату, технику, URL и лицензию. Эти сведения часто повторяются в `summary` и тегах. Существенные признаки входят в текст, когда есть во входных полях. Для `20` сохранились `birds` и `птицы` из каталога. У `18` бороды нет ни в AI-полях, ни в каталожных тегах.

PHP и FastAPI не вводят отдельного ограничения на длину собранной строки. До сборки AI-схема ограничивает `summary` 1000 символами, каждый список нормализуется до 15 уникальных значений. ## 8. Рекомендации для 5.4-0B
